## 9. Order processing and customer-specific routing

When a visitor submits an order:

1. Resolve the published link token on the server.
2. Load the correct saved customer and link configuration.
3. Validate the selected bundle and its server-defined USD price.
4. Validate required visitor fields.
5. Save the order with a unique reference, customer ID, link ID, bundle, amount, timestamp, and actual payment status.
6. Queue the notification using the destination associated with that order's link configuration.
7. Record delivery attempts and results.
8. Retry temporary delivery failures safely.

Capture the intended recipient and relevant configuration version when the notification is queued so subsequent edits cannot silently reroute an existing queued order to another customer's chat.
