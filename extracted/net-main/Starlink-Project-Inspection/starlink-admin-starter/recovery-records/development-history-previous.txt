For a new Supabase project, create the project and run this migration in SQL Editor. For an existing database, review it and take a backup before applying it; although it has no `DROP` statements, it creates or replaces database objects.

Before using the app, configure backend-only `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_EMAIL`, `ADMIN_PASSWORD_HASH`, `JWT_SECRET`, and `TELEGRAM_BOT_TOKEN`. Telegram testing requires a real bot token and a customer Chat ID; the customer must start the bot in a private chat or add it to a group where it can send messages.

For deployment, the supplied README documents a Render backend rooted at `backend` (`npm install`, `npm start`, health path `/health`) and a Vercel frontend rooted at `frontend` (`npm run build`, output `dist`). Configure `VITE_API_URL` on Vercel to the actual Render API URL, then set the backend CORS and public URL variables to the verified frontend domain.
